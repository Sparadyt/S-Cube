A simple cubing tool.

# How to Run:
* Install [.NET Version 10](https://dotnet.microsoft.com/en-us/download/dotnet/thank-you/sdk-10.0.203-windows-x64-installer)
* Download the code as .zip
* Unzip the code
* Open the program and double click the file called "S-Cube"

* Double click the .lnk shortcut

# Types of Solves:

## -Bare Bones

It contains bare minimum. Useful for quick solves where you don't want to analyse a lot

### Bare Bone Features:

* Time
* Date


## -Advance

It contains a lot of features. Useful if you want to analyse a lot

### Advance Features:

* Time
* Date
* Folder
* Lap
