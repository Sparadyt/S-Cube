A simple cubing tool.

# How to Run:
* Install [.NET Version 9](https://dotnet.microsoft.com/en-us/download/dotnet/thank-you/sdk-9.0.312-windows-x64-installer
* Download the code as .zip
* Unzip the code
* Double click the .lnk shortcut

# Types of Solves:

## -Bare Bones

It contains bare minimum. Useful for quick solves where you don't want to analyse a lot

### Bare Bone Features:

* Time
* Date


## -Advance

It contains a lot of features. Useful if you want to analyse a lot\

### Advance Features:

* Time
* Date
* Folder
* Lap
